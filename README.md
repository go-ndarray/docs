# go-ndarray docs

Documentation site for [go-ndarray](https://github.com/go-ndarray/ndarray) —
built with MkDocs Material, versioned with [mike](https://github.com/jimporter/mike),
and served at <https://go-ndarray.github.io/docs/>.

## Local preview

```sh
pip install -r requirements.txt
mkdocs serve
```

Pushing to `main` deploys the `latest` version to the `gh-pages` branch via
GitHub Actions; GitHub Pages serves it under `/docs/`.
